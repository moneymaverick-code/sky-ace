# 스카이 에이스 (가제)

적을 쏘아 떨어뜨리는 비행기 슈팅 게임이에요.
세로 모드와 가로 모드 두 가지로 놀 수 있어요.
판을 깨고 모은 돈으로 격납고에서 비행기를 키우고 꾸며요.
갤럭시(안드로이드)와 PC(윈도우) 둘 다 돼요.

> 게임 코드는 이 저장소에 없어요.
> 여기는 설치 파일을 받는 곳이에요.

## 받기

- 갤럭시(안드로이드): https://github.com/moneymaverick-code/sky-ace/releases/latest/download/sky-ace.apk
- PC(윈도우): https://github.com/moneymaverick-code/sky-ace/releases/latest/download/sky-ace-setup.exe

두 주소는 늘 가장 새 판을 받아요.
바뀐 내용은 [Releases](../../releases/latest) 에 적어 둬요.

## 0.2 에서 새로 생긴 것

- 비행기 13대 (일반 8대 + 비밀 5대)
- 비행기마다 다른 주무기 (부채꼴·관통탄·어뢰·8방향·유도 로켓·레이저 등)
- 비행기 꾸미기: 도색 8가지·직접 3색·꼬리 엠블럼·비행운 색·보조무기
- 비밀 비행기 5대가 숨어 있어요 (일반 비행기보다 세요)
- 가로 모드: 왼쪽에서 오른쪽으로 날아가는 '구름 협곡' 1~3탄 + 보스
- 지도에서 세로 모드 / 가로 모드 고르기 (코인·비행기·꾸미기는 함께 써요)
- 반투명 폭탄 버튼

## 0.2.1 에서 새로 생긴 것

- 샘플 모드: 처음부터 비행기 13대·꾸미기·1~3탄이 전부 열려 있어요 (설정에서 '샘플 모드'를 끄면 원래 진행으로 돌아가요)

## 0.3 에서 새로 생긴 것

- 실사 그래픽: 세로·가로 1~3탄, 격납고·지도·조종석 체험까지 실제 하늘·바다·섬·구름 느낌으로 바뀌었어요
- 총알도 실사: 빛나는 예광탄, 날아오는 쪽으로 긴 적 탄두·불꽃 꼬리, 사진 같은 폭발·연기
- 상점: 고른 비행기만 따로 강화해요 (부품 6종 엔진·기관포·탄창·장갑·미사일 포드·필살기 코어, 각 10단계)
- 소모품 5종: 시작 방패·폭탄 +1·자석 시작·코인 2배·필살기 50% 시작 (출격 전에 골라요)
- 판마다 대장: 세로 3종·가로 3종, 2단계에서 공격이 바뀌어요
- 필살기 13종: 비행기마다 달라요 (게이지가 차면 필살기 버튼, PC 는 E 키 또는 마우스 오른쪽)
- 난이도 4단계: 쉬움·보통·어려움·지옥
- 조종석 체험: 지도에서 '조종석 체험' 버튼
- 0.2.x 위에 덮어 설치하면 진행은 보통 난이도로, 예전 강화는 가진 비행기 전부에 그대로 이어져요
- 실제 돈 결제·광고는 없어요

## 업데이트

같은 받기 주소에서 새 파일을 받아 **덮어 설치**하면 돼요.
지우지 않고 덮어 설치하면 저장이 그대로 이어져요.

## 갤럭시 설치 방법

1. 폰 인터넷에서 위 갤럭시 받기 주소를 열어요.
2. 받기가 끝나면 알림이나 **내 파일 → 다운로드** 에서 `sky-ace.apk` 를 눌러요.
3. "출처를 알 수 없는 앱" 안내가 뜨면 **설정 → 이 출처 허용** 을 켜고 뒤로 와요.
4. **설치** 를 눌러요.
   "Play 프로텍트" 경고가 뜨면 **세부정보 더보기 → 무시하고 설치** 를 눌러요.
   (가게에 올린 앱이 아니라서 뜨는 안내예요.)
5. 끝나면 **열기**.
6. 가로 모드는 전투가 시작되면 폰을 가로로 돌려서 해요.

## PC 설치 방법

1. 위 PC 받기 주소로 `sky-ace-setup.exe` 를 받아요.
2. 받은 파일을 두 번 눌러요.
3. "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행** 을 눌러요.
   (서명 인증서를 사지 않은 시험판이라 뜨는 안내예요.)
4. 안내대로 **다음 → 설치** 를 누르면 바탕화면에 '스카이 에이스' 가 생겨요.

## 성능 기록

갤럭시 판은 한 판이 끝나면 기기 이름·화면 크기·초당 화면 수(fps) 같은 성능 숫자만 서버에 보내요.
이름·연락처 같은 개인 정보는 보내지 않아요.
